How to Play

From login to flag submission — full walkthrough.

1

Select Event

Choose category → Select event → Enter code (if required) or join free.

2

Reserve Slot

Pick a time slot → Click Reserve. Countdown starts — your spot is locked.

3

Camera Check

Quick webcam verification. Allow camera access. Face detection confirms you're there.

4

Wait for Start

Stay on the page. When countdown hits zero → START button appears.

5

Solve & Submit

Inside secure environment: solve challenges, submit flags as flag{...}. Each correct flag = points.

Pro tip: Use the built-in browser, notepad, and terminal tools inside the secure environment.

Troubleshooting

Common issues and fixes.

App won't open / crashes

• Run as administrator (Windows) or fix Gatekeeper (Mac).

• Delete and reinstall the app.

• Make sure you have the latest version.

Connection error during login

• Check internet connection.

• Disable VPN or proxy.

• Make sure hacklayer.com is not blocked by firewall.

Camera not detected

• Allow camera permission when prompted.

• Close other apps using camera (Zoom, Teams).

• On Linux: install libgstreamer.

Slot reservation failed

• Slot may be taken — try another one.

• Re-login if session expired.

• Check if event requires an access code.

Security violation warning

• Close screen recording apps.

• Disconnect extra monitors.

• Close proxy tools and VPN.

White screen / stuck loading

• Wait 10-15 seconds (first load can be slow).

• Check internet and restart app.

• Reinstall — your data is on server, nothing lost.
